# VolunteerHub

VolunteerHub is a React application powered by Vite. The repository is
organized into `Frontend` and `Backend` folders. The React app currently lives
in `Frontend`; `Backend` is a placeholder for future server-side code.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Development

```sh
npm install
npm run dev
```

Vite prints the local development URL after the server starts.

## Production

```sh
npm run build
npm run preview
```

`npm run start` starts the Vite development server and is provided for preview
environments that expect a root-level `start` script. Root scripts forward to
the frontend workspace.
